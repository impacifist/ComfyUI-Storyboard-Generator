# Interactive sample

Public URL: https://impacifist.github.io/ComfyUI-Storyboard-Generator/

This is an independent, static walkthrough, not a hosted ComfyUI instance. It uses the public authored “Before the rain stops” sample in English, Korean and Japanese. Characters and story shots are fixed. Visitors can inspect direction, compare H3/Seedance/LTX text prompts, switch between 10- and 15-second clip budgets, copy/download prompts, select individual clips and download connected STRING-node workflows.

`tools/build_demo.py` uses the pinned shared planner/formatter and `clip_snapshot.make_bundle` to produce 18 sample bundles. Direction prose is authored from the English sample, not generated by an AI. The browser loads only static files; it has no credential fields, analytics, API requests, uploads, remote models or ComfyUI execution. Only the UI-language preference persists. Existing demo nodes retain their original conversion when the visitor switches language/model. Reloading clears the demo workspace.

Downloaded workflow JSON contains real `StoryboardClipPrompt → PreviewAny` connections with validated portable snapshots. Import requires this node pack and ComfyUI's built-in Preview Any node. Running it outputs saved text, not video. The browser's node view is an illustration, not LiteGraph or an attached ComfyUI canvas.

## Build and verify

```powershell
python tools/build_demo.py
python -m unittest discover -s tests -q
python tools/test_demo_browser.py
```

To additionally import and queue the browser-exported workflow in an isolated CPU-only ComfyUI:

```powershell
python tools/test_comfy.py --comfy <COMFY_DIRECTORY> --python <COMFY_PYTHON> --demo-workflow storage/browser-check/demo-exported-workflow.json
```

The build destination is restricted to ignored `dist/` paths. Only `index.html`, `demo.css`, `demo.js`, `workflow.js`, the built public `data.json` and `.nojekyll` are deployed. Private settings, storage, the whole checkout, videos and screenshots are never copied into the Pages artifact. The sample JSON files were copied from the already-public standalone examples and validated before inclusion. Do not replace them with raw user feedback or private storyboards.

`.github/workflows/pages.yml` runs unit tests, builds this allowlist, and deploys only `dist/site` through GitHub Pages. Build has read-only repository permissions; the deployment job has only Pages/OIDC permissions. Runtime nodes and the standalone app are unaffected.

The vendored source uses canonical Git archive bytes (`core.autocrlf=false`) and `_vendor/** -text` attributes so Linux and Windows verify the same hashes. The CI runner installs the existing ComfyUI `aiohttp` dependency for route tests; the site itself has no Python runtime or client dependencies.
