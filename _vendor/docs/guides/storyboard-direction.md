# 콘티 단계의 샷·편집 설계

콘티 생성·재생성과 AI 의미 검수가 공유하는 애플리케이션 지침이다.
MiniMax 공식 문서의 컷 연결, 공간 앵커, 컷 내부 연기 설계를 참고했다.
특정 3D 화풍, 코미디 훅 할당량, 매초 카메라 변경은 강제하지 않는다.
일본 2D 애니메이션 기본 연출과 변환 계약은 anime-direction.md, 추가 조사 근거는 storyboard-direction-research.md를 함께 참고한다.
사용자 제공 이미지의 카메라 기법 001~075 한국어 번역과 프롬프트는 [camera-techniques.ko.md](camera-techniques.ko.md)를 참고한다. 장면 목적에 맞게 선택하고 사용 횟수나 종류를 강제하지 않는다.

참고:

## 장면 전체를 먼저 설계

사용자의 화풍과 분위기를 유지하며 감정 변화 → 관객이 봐야 할 대상 → 구도 → 전환 계기 → 다음 컷 연결 순서로 설계한다.
beats에는 사건뿐 아니라 인물의 욕구와 상대의 반응 때문에 감정이나 관계가 바뀌는 흐름을 담는다.
대사마다 화자를 번갈아 비추거나 와이드·미디엄·클로즈업을 기계적으로 순환하지 않는다.
대사의 영향이 중요하면 듣는 사람의 반응을 보여주고, 침묵·시선·손·소품이 의미를 전달하면 그 대상을 선택한다.
설정 샷, 투샷, 오버숄더, 반응 샷, 인서트, 클로즈업은 필요한 경우만 쓴다. 모든 종류를 채울 필요는 없다.
공간을 이미 이해할 수 있으면 설정 샷을 추가하지 않는다. 같은 구도를 유지하는 것도 감정과 리듬에 목적이 있으면 허용한다.

## 대사와 상황에서 구도를 선택

아래는 이 앱의 창작 선택 지침이며 특정 스튜디오의 정답이나 필수 샷 목록이 아니다.
75가지 기법 목록을 고르기 전에 각 beat에서 관객이 알아차릴 변화를 찾는다.
대사의 문장 내용, 화자의 의도, 듣는 사람의 해석, 말과 행동의 불일치를 함께 읽는다.
그중 이번 컷의 중심을 하나 정하고 기존 purpose에 무엇을 왜 보여주는지 구체적으로 쓴다.
대사를 말하는 인물과 화면의 주인공은 달라도 된다. 화면 밖 화자의 대사도 원래 speaker ID로 보존한다.

| 이야기에서 읽을 단서 | 선택할 수 있는 화면 | 구체화할 내용 |
|---|---|---|
| 상대의 말이 마음을 바꾸거나 상처를 줌 | 듣는 사람의 리액션 클로즈업, 화자의 어깨를 전경에 둔 오버숄더 | 반응을 읽을 눈·입·손 중 핵심 하나, 상대가 화면 안/밖 어디에 있는지, 반응을 기다릴 여운 |
| 말과 속마음이 다름, 망설이거나 무언가를 숨김 | 얼굴을 전부 설명하지 않는 옆얼굴·부분 클로즈업, 손이나 이미 설정된 소품 인서트 | 대사와 대비되는 관찰 가능한 행동; 표정이 핵심이면 표정을 가리지 않음 |
| 가까워짐, 멀어짐, 화해 또는 관계의 단절 | 거리 변화가 읽히는 투샷·측면 구도, 여백을 둔 분리 구도 | 인물 사이 간격, 같은/다른 깊이, 시선이 만나는지, 변화 전후의 화면 배치 |
| 질문, 설득, 맞섬, 주도권의 이동 | 비대칭 오버숄더, 한 인물에 무게를 둔 전경·중경 배치; 필요한 경우 절제된 높이 차 | 누구의 관점인지와 왜 지금 바뀌는지; 성별·연령만으로 위계나 앵글을 결정하지 않음 |
| 관객이나 인물이 새로운 정보를 발견함 | 이미 존재하는 대상의 인서트 → 인식하는 인물의 반응, 시선에 연결된 주관 샷, 가림 뒤의 드러남 | 정보 공개 순서와 볼 수 있는 범위; 별도 시점으로 컷하면 기존 요청 컷 안에서 분리 |
| 움직임, 소품 전달, 진입·퇴장이 사건을 바꿈 | 동선이 읽히는 와이드·측면·깊이 구도, 행동 디테일 | 이동할 여백, 전달하는 손과 받는 대상, 출입 방향; 이후 반응을 위해 필요한 공간 |
| 침묵, 기다림, 소외감 또는 장면의 여운 | 인물보다 공간이 읽히는 와이드, 빈 자리·남겨진 소품과 인물의 배치, 유지하는 리액션 샷 | 기존 장소와 소품만 사용해 무엇이 남았는지 보여줌; 분위기를 위해 새 사건을 만들지 않음 |
| 3~5명 사이의 동맹, 방관, 소외 또는 반응의 전달 | 관계가 읽히는 그룹 마스터, 주요 두 인물과 관찰자를 나눈 깊이 구도, 선택적 리액션 | 주도 인물·응답 인물·관찰자의 위치; 모든 얼굴을 매 컷 같은 크기로 나열하지 않음 |

구도는 샷 크기만으로 결정하지 않는다. 장면에 필요한 화면상 위치, 여백, 옆얼굴/정면/뒷모습,
전경·중경·후경, 서로 겹치는 정도, 시선 방향 중 의미 있는 요소를 골라 visual에 적는다.
선택한 요소는 실제 프레이밍으로 관찰 가능해야 한다. 추상적인 '감성적 구도'나 기법명 나열로 대신하지 않는다.
인물의 눈·손·소품을 강조할 때 해당 부분이 화면에 들어오는 크기와 크롭을 지정한다.
작은 손동작을 넓은 전신 샷에서만 보여주거나, 얼굴이 잘린 인서트에 미세한 표정 연기를 요구하지 않는다.
2D에서는 배치·겹침·선택적 움직임으로 깊이와 주의를 표현할 수 있다. 렌즈 효과나 실사식 초점 이동은 필수가 아니다.

### 컷의 대비와 감정 리듬

출력 전 요청된 컷 수 안에서 주의 대상 → 구도 → 전환 계기의 흐름을 먼저 구성한다.
이전 컷과 비교해 새 정보·반응·관계 변화가 있으면 대상, 거리, 시점, 깊이 중 필요한 요소를 바꾼다.
변화가 없다면 대사 화자가 바뀌었다는 이유만으로 컷하지 말고 같은 구도 안에서 반응을 기다릴 수 있다.
비슷한 크기와 각도로 연속 컷할 때에는 시선 연결, 명확한 대상 변화 또는 의도적인 대비를 설명해 불필요한 점프 컷을 피한다.
정점은 더 큰 카메라 움직임 대신 처음으로 가까이 보는 얼굴, 분리돼 있던 인물이 함께 들어오는 투샷,
혹은 비어버린 프레임으로 강조할 수도 있다. 이야기의 변화가 뒷받침할 때만 선택한다.
짧은 예: 농담을 함께 듣는 투샷 → 의미가 달라지는 말에 듣는 사람의 반응 → 답변 뒤 달라진 거리의 투샷.
이 예의 컷 수와 순서를 다른 장면에 복제하지 않는다. 단일 감정 흐름이면 하나의 유지 샷이 더 적절할 수 있다.
가림·소품·인물 이동을 연출 재료로 쓰더라도 입력에 없는 설정을 지어내거나 얼굴·동작을 읽기 어렵게 만들지 않는다.
풍부함을 위해 요청 컷 수, 전체 시간, 대사, 고정 컷을 변경하지 않는다. 주된 카메라 움직임은 필요한 경우 하나를 선택한다.

## 기존 컷 필드에 설계 의도를 기록

- purpose: 이 컷이 전달할 정보·감정과 지금 이 대상을 보여주는 이유.
- visual: 주된 화면 대상, 인물의 화면상 위치·깊이·시선, 필요한 랜드마크와 구도. 화면 밖 인물은 상태에서 추적한다.
- actions: 컷 안의 시작 → 핵심 변화 → 여운 순서로 관찰 가능한 연기를 기록한다. 매초 새 동작을 채우지 말고 정지, 망설임, 반응을 기다리는 시간도 확보한다.
- camera: size와 angle은 관객의 주의와 감정에 맞춘다. movement는 필요한 경우만 쓰고 고정 구도 안의 연기로 충분하면 고정한다. transition에는 다음 컷 전환의 방식과 계기, 마지막 컷에는 마무리 방식을 쓴다.
- continuity: 이전 컷에서 이어받는 시선·동작·소품·감정·소리와 다음 컷에 넘길 상태. 첫 컷은 출발 상태, 마지막 컷은 도달 상태를 기록한다.
- duration: 대사, 동작, 반응과 여운에 필요한 시간을 배정한다. 총 길이와 컷 수를 지키되 기계적으로 균등 분할하지 않는다. 실제 리듬이 같다면 동일 길이도 허용한다.

## 모든 행동의 선행 조건과 결과

[action-causality.md](action-causality.md)의 공통 인과 설계를 생성·재생성·검수에 적용한다.
주요 행동·반응·감정 변화마다 필요한 조건을 역으로 찾고, 입력에서 출발해 조건 성립 → 행동 → 결과가 순서대로 가능한지 확인한다.
공간·환경뿐 아니라 소지와 사용 가능 상태, 지각과 지식, 동기, 시간과 결과의 지속까지 확인한다.
이미 성립한 준비를 반복하거나 모든 단계를 별도 컷으로 늘리지 않는다. 필요한 보완은 기존 필드와 요청 시간·컷 수 안에 반영한다.
이 기준은 특정 장소나 행동 목록으로 제한하지 않는다. 원문의 의도·고정 컷·세계 규칙을 지키며 해결할 수 없는 충돌은 검수 의견으로 구분한다.

## 공간과 편집의 연결

대화 장면에서는 두 인물의 위치 관계, 시선 방향과 카메라가 보는 쪽을 먼저 정한다.
이유 없이 좌우 관계나 시선 방향을 뒤집지 않는다. 카메라 이동이나 축을 넘는 의도적 전환은 관객이 이해할 수 있도록 설명한다.
세계 속 인물·소품 위치와 화면상 위치를 구분한다. 카메라 각도가 바뀌면 화면상 랜드마크 위치도 달라질 수 있으며 그 이유를 기록한다.
인물 이동, 소품 전달, 시간 경과는 실제 행동이나 명시적 전환으로 연결한다. 컷 전환 자체가 세계 상태를 초기화하지 않는다.
한 컷 안의 여러 연기 단계와 여러 카메라 컷을 구분한다. 새 시점으로 컷하면 별도 shot으로 설계하고 한 shot 안에 설명되지 않은 하드 컷을 숨기지 않는다.
15초 생성 클립 경계는 기술적 분할이다. 이 경계 때문에 이야기를 재시작하거나 새 카메라 컷을 강제로 추가하지 않는다.

## 검수와 수정의 경계

컷의 목적, 주의 대상, 전환 계기와 앞뒤 연결을 함께 읽고 불필요한 컷, 설명 없이 바뀌는 시점, 목적 없는 카메라 이동을 검토한다.
행동·반응·변화의 선행 조건과 결과를 전체 컷 흐름에서 검수한다. 모순, 정보 누락, 문맥상 성립하는 생략을 구분하고 해당 컷과 선행 근거를 지목한다.
대화의 의미 변화가 있는데 계속 같은 대상을 같은 각도로 보여주는지, 중요한 반응·행동이 프레이밍 밖이거나 너무 작지 않은지 확인한다.
의미 검수에서 개선이 필요하면 해당 shot_id와 놓친 감정/정보를 지목하고, 기존 사건·대사·시간 안에서 가능한 구도 대안을 제시한다.
단순히 '더 다양한 카메라'라고 지적하거나 다양성 점수·기법 개수로 경고하지 않는다. 의도적인 반복과 유지 샷은 인정한다.
클로즈업 비율이나 구도 사용 횟수로 품질을 판정하지 않는다. 반복도 장면에 필요한지 판단한다.
재생성에서는 고정 컷과 사용자 설정을 지키고 수정 가능한 앞뒤 컷을 연결한다. 연출 개선을 이유로 사건·대사·결말을 임의로 교체하지 않는다.
이 기준은 새 필수 JSON 필드나 저장 차단 조건이 아니다. 형식 검증으로 창작 품질을 보장했다고 주장하지 않는다.
