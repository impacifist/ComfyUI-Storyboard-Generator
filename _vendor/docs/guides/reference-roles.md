# Reference selections

The user selects a character or background and the part of the image to use. Descriptions are optional. Each manifest entry includes English guidance for its role; this is an application default, not an observation of the image. Never claim to have inspected an attachment.

appearance is the basic character reference: face, hairstyle, clothing, colors and accessories. face is face and hairstyle only. body is proportions and silhouette, outfit is clothing/accessories, expression is acting reference, and detail uses the user's specific note. environment is location layout, never an extra person.

Multiple images for one character are views or feature references for that same person. Do not turn them into additional characters. Component-specific images refine that component rather than blending every face or outfit together. Explicit reference notes refine or limit the default role; preserve them. Keep the approved storyboard's actions, camera and story intent.

A blank note is valid for ordinary appearance, face, body, outfit, expression and environment selections. Use the role's default guidance without asking the user to invent visual attributes. An unprovided detail is unknown; do not fabricate it. Keep attachment order and labels exact for the target model.
