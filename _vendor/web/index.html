체크한 컷만 변환합니다. 각 컷을 펼쳐 대사와 연출을 확인하세요.

영상 설정

영상 지시문은 영어로, 대사는 원문 그대로 출력합니다.

각 클립의 시작 이미지는 영상 제작 워크플로우에서 직접 연결하세요. 여기서는 이미지를 분석하거나 LTX 노드로 전송하지 않습니다. 정확한 프롬프트를 사용하려면 LTX의 Prompt Enhance를 끄세요.

캐릭터·배경 참조 이미지

캐릭터와 배경에 여러 장을 추가할 수 있습니다. 합쳐서 9장, 장당 5MB 이하 PNG·JPEG·WebP.

이미지는 이 PC에 보관합니다. 변환 AI에는 이미지의 캐릭터·용도·설명만 전송하며 이미지 자체를 분석하지 않습니다. 영상 제작 시 ZIP의 순서대로 직접 첨부하세요.

배경 참조 이미지

같은 장소의 전체 구조와 다른 각도를 추가하세요. 설명에 적용할 장소, 좌석·문·창문·통로의 위치와 캐릭터가 앉을 자리를 적으면 구도 유지에 도움이 됩니다.

클립 분할

콘티의 컷과 대사에 맞춰 길이를 추천합니다. 아래에서 클립별 초만 바꾸면 됩니다. 전체 길이는 달라질 수 있으며 원본 콘티는 유지됩니다.
